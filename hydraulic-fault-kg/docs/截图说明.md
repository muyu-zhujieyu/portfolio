## 浏览器设置建议

1. **缩放比例**: 125% 或 150%（Chrome: Ctrl+加号）
2. **全屏模式**: F11
3. **截图区域**: 16:9 比例（1920×1080 或 1280×720）
4. **截图工具**: Windows 截图工具（Win+Shift+S）或浏览器开发者工具截图
