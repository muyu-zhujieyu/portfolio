## 导出步骤

### 使用 SolidWorks

1. 启动 SolidWorks
2. 菜单：文件 → 打开 → 选择：
   `D:\kg0623\20250521【公开】Y1797-ZT.x_t`
3. 调整视图到适合展示的轴测视角（建议等轴测视图）
4. 菜单：文件 → 另存为 → 选择保存类型：PNG (*.png)
5. 文件名：`servo_valve_model.png`
6. 保存路径：`D:\kg0623\frontend\public\servo_valve_model.png`
7. 建议导出分辨率：1920×1080 或更高

### 使用其他 CAD 软件

1. 用支持的 CAD 软件打开 `.x_t` 文件
2. 调整到轴测视角
3. 导出为 PNG 格式
4. 命名为 `servo_valve_model.png`
5. 保存到 `D:\kg0623\frontend\public\`
