# 作品集｜G1 SLAM 导航与安全运动平台

面向 Unitree G1 人形机器人的实机建图、导航与上肢运动实验工程。项目以 MID360 点云和 IMU 为感知输入，通过 FAST-LIO 生成里程计与三维点云地图，将 PCD 处理为 Nav2 二维占据栅格，再通过受限速度桥接把 `/cmd_vel` 转换为 G1 高层运动命令；相邻运动模块支持双臂姿态采集、轨迹编辑、FK/IK 和视觉目标触碰的安全预演。

**[打开公开交互仿真](index.html)**

> 公开版只展示产品逻辑、架构和浏览器仿真，不包含现场 IP、SSH 配置、真实地图、PCD 点云、模型权重、标定数据、部署历史或可直接驱动真机的控制源码。

## 已验证基线

v0.1 完成了 G1 实机上的最小导航闭环：

```text
MID360 点云 + IMU
  → FAST-LIO /Odometry 与 3D PCD
  → PCD 清洗、切片与 2D occupancy map
  → fixed-start 位姿对齐
  → Nav2 路径规划与控制
  → /cmd_vel 限幅桥接
  → G1 高层速度接口
```

基线支持单会话连续目标导航；每次到达后关闭速度桥接、执行 `stop_move` 并回到等待状态。它没有实现任意初始位置下的自动重定位，启动前仍需人工将机器人放置在地图原点附近。

## 产品能力

| 模块 | 能力 | 关键工程判断 |
| --- | --- | --- |
| SLAM | 复用 G1 内置 MID360 点云/IMU，FAST-LIO 输出里程计与 PCD | 检查节点唯一性和里程计新鲜度，避免僵死进程 |
| 地图处理 | 高度切片、密度/离群点过滤、障碍膨胀、PGM/YAML 输出 | 大型原始 PCD 与小型派生地图分开管理 |
| 定位 | 第一帧稳定里程计与人工固定起点对齐 | 先验证闭环，再引入 AMCL 等全局重定位 |
| Nav2 | 静态地图加载、路径验证、目标执行和状态回收 | 目标执行前先规划，结束后关闭运动桥接 |
| 运动桥接 | 速度限幅、禁用不安全自由度、偏航方向修正 | 真机接口默认锁定，STOP 是独立收口路径 |
| 双臂运动 | 关节控制、姿态采集、FK/IK、轨迹编译与播放 | 单 owner、FSM/限位检查、50 Hz 平滑推进 |
| 视觉触碰实验 | D435i、YOLO、深度选点、坐标变换与端点 IK 检查 | 未完成碰撞、力反馈和完整标定前保持人工确认与 dry-run |

## 交互仿真

公开 Demo 使用脱敏二维地图和本地状态机，可体验：

- 选择装配区、检查区或 HOME 作为导航目标。
- 完成固定起点、里程计、地图和急停四项启动前确认。
- 查看 A* 路径、机器人移动、桥接启用与到点自动锁定。
- 任意时刻执行 STOP，模拟桥接关闭和 `stop_move` 收口。
- 运行视觉目标锁定与 IK 指标检查；真机执行按钮始终禁用。

该仿真由原生 HTML、CSS、JavaScript 实现，不发送网络请求。

## 安全与公开边界

- 仿真中的地图、坐标、目标和遥测均为合成数据。
- 不公开真实网络拓扑、设备账号、现场地图、点云、部署包和模型权重。
- “目标可见”“IK 可达”不等于路径无碰撞或工具已安全接触。
- 真实机器人运动必须在吊架、现场监护和硬件急停可用的条件下分级验证。
- 当前视觉触碰实验没有自碰撞、环境碰撞、力/力矩或触觉闭环，不能无人看守运行。
