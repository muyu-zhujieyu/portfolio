# 作品集｜液压泵近端巡检状态监测平台

面向液压泵试验、调试与现场巡检的端—边—Web 状态监测产品。系统将嵌入式四通道采集、TCP 数据接入、WebSocket 实时推送、响应式 Web/PWA 展示和 CSV 归档串成一条可观察链路，让研发、试验和运维人员能够同时核对设备编号、通信状态、实时参数、趋势变化与巡检记录。

**[打开脱敏交互演示](index.html)**

> 这是依据项目说明书与源码排版稿重建的作品集演示版。页面使用本地模拟数据，不连接真实终端，也不包含软著申请表、合作协议、签章、硬件地址、现场数据或原始申报文件。

## 解决的问题

液压泵近端巡检往往同时面对“采集是否正常”和“设备参数怎样变化”两类问题。分散仪表、终端日志和人工抄录难以对齐时间，多层网络中断又容易让使用者误把链路故障当作设备异常。本项目重点解决：

- 将四路参数绑定到同一设备编号和采集时间，形成一致的数据对应关系。
- 区分数据服务未连接、采集终端离线、数据接收暂停和页面暂停显示。
- 同时支持宽屏监控位与移动近端巡检，复用同一套字段和数据服务。
- 用趋势、当前值、统计和记录表支持现场核对，并通过 CSV 完成会话归档。

## 产品能力

| 能力 | 产品表现 | 价值 |
| --- | --- | --- |
| 四通道实时监测 | 泄油口温度、泄油口压力、油口 A/B 压力同步显示 | 将分散测点放入同一时间视图 |
| 链路状态分层 | 页面服务、采集终端和数据时效分别呈现 | 快速判断问题位于浏览器、网络还是终端 |
| 趋势与单项详情 | 总体趋势、单通道趋势、最大/最小/平均/峰峰值 | 支持工况阶段对照和局部变化检查 |
| 巡检记录 | 时间排序、分页/最近记录和当前会话缓存 | 从曲线回到具体时刻和数值 |
| CSV 导出 | UTF-8 字段化导出 | 为试验复核和后续分析保留输入 |
| Web/PWA 双端 | 宽屏工作台与移动单列布局 | 满足监控工位与设备近端两种场景 |

## 系统链路

```text
温度 / 压力传感器
        ↓ 四路 ADC
NXP KL26Z4 + W5500 采集终端
        ↓ TCP 字节流（分包 / 粘包处理）
Node.js 数据接收与短期缓存
        ↓ WebSocket 实时帧、增量记录、终端状态
React Web / PWA
        ↓
趋势观察、巡检记录、CSV 归档
```

详细需求和验收标准见 [产品需求文档](docs/PRD.md)，工程边界见 [架构说明](docs/ARCHITECTURE.md)。

## 体验演示

直接打开 `index.html`，或从 GitHub Pages 作品集首页进入。演示支持：

- 查看四个指标的实时模拟值与总体趋势。
- 暂停/继续页面显示，理解其与终端连接的区别。
- 模拟终端离线并观察链路状态变化。
- 查看最近巡检记录并导出 UTF-8 CSV。
- 阅读通道含义、系统链路和数据使用边界。

该演示采用原生 HTML、CSS 和 JavaScript，无需安装依赖，也不会发送数据。
