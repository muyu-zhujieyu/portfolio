# 作品集｜轻习惯 LiteHabit

> 一款强调「轻量开始、即时反馈、看见积累」的本地优先习惯追踪 Web App。

[在线体验](https://muyu-zhujieyu.github.io/portfolio/) · [产品需求文档](./LiteHabit_PRD_v2.0.docx)

## 项目概览

很多习惯工具在开始阶段就要求用户完成复杂配置，长期使用又容易被数据压力反噬。LiteHabit 将核心体验收敛为三个动作：选择一个足够小的习惯、完成今日打卡、从趋势中看见积累。

- 项目类型：AI 辅助产品设计与前端原型
- 我的角色：产品设计、交互设计、视觉设计、前端实现、PRD 输出
- 交付形态：可运行 Web App + 完整 PRD
- 数据策略：localStorage 本地持久化，无账号、无数据上传

## 核心体验

- 今日习惯清单，一键打卡并支持撤销
- 12 个预设习惯、分类筛选与自定义习惯
- 自定义图标、分类和提醒时间
- 今日完成率、当前连续天数、历史最长连续天数
- 最近 7 天趋势图、28 天热力图与阶段成就
- 根据当前状态生成本地轻教练建议
- 深色模式、JSON 数据备份、CSV 打卡记录导出
- 响应式布局，兼容桌面端与移动端

## 产品设计思路

1. **降低启动成本**：用预设模板和低门槛目标帮助用户立即开始。
2. **强化即时反馈**：通过完成率、连续天数和轻量动效建立正向回路。
3. **呈现长期价值**：用趋势、热力图和里程碑让微小行动变得可见。
4. **尊重数据隐私**：默认只在浏览器本地保存个人记录。

## 技术实现

- HTML5
- CSS3（响应式布局、深色模式、动效）
- 原生 JavaScript
- Canvas 趋势图
- localStorage 本地存储
- GitHub Pages 自动部署

## 本地运行

直接打开 `index.html`，或在项目目录启动任意静态文件服务器。

使用 VS Code Live Server 时，右键 `index.html`，选择 **Open with Live Server**。

## 数据说明

数据保存在当前浏览器的 `liteHabitData` 键中。清理浏览器数据会导致记录丢失，重要记录请定期导出 JSON 备份。
